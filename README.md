# 📁 Enterprise Network Playbook

Welcome to my technical repository! I am a Network Engineer documenting my practical journey in building, securing, and managing enterprise networks. 

This repository is not just a collection of Command-Line Interface (CLI) configurations. It is a comprehensive **Playbook** showcasing hands-on network design, traffic management, security implementation, and troubleshooting.

---

## 🗺️ Repository Structure

Navigate through the sections below to view topology designs, configuration files, and detailed explanations for each lab:

* 🌐 **[01-Routing-Fundamentals](./01-Routing-Fundamentals):** Static and Default Routing, OSPF (Single-Area & Tuning), NAT (Network Address Translation), and WAN connectivity.
* 🎛️ **[02-Switching-Core](./02-Switching-Core):** VLANs, Trunking (802.1Q), Inter-VLAN Routing (Router-on-a-Stick & Layer 3 Switches), EtherChannel (LACP), Spanning Tree Protocol (STP), and WLAN setup.
* 🛡️ **[03-Network-Security](./03-Network-Security):** Layer 2 Security (Port Security, DHCP Snooping, Dynamic ARP Inspection), Access Control Lists (ACLs), and Device Hardening (SSH, Passwords).
* ⚙️ **[04-Network-Services-Management](./04-Network-Services-Management):** DHCP Server Configurations, NTP (Network Time Protocol), Syslog, and Device Discovery Protocols (CDP & LLDP).
* 🏆 **[05-Integrated-Enterprise-Project](./05-Integrated-Enterprise-Project):** The ultimate Capstone Project combining all the above technologies into a single, fully secured enterprise infrastructure. Includes configuration files, network topology maps, and a vertical video walkthrough demonstrating the working network.

---

## 🛠️ Technologies & Tools

* **Simulators:** Cisco Packet Tracer / GNS3 / EVE-NG.
* **Routing Protocols & Services:** Static/Default Routing, OSPF, NAT, PAT, HSRP.
* **Switching Technologies:** VLANs, Trunking, Inter-VLAN Routing, EtherChannel, STP.
* **Network Security:** Port Security, DHCP Snooping, DAI, Standard & Extended ACLs.
* **Network Management:** DHCP, NTP, Syslog, CDP, LLDP.

---

## 📈 Repository Objective

The main objective of this playbook is to demonstrate the transition from understanding isolated network protocols to designing a complete, secure, and reliable enterprise infrastructure that meets real-world business requirements.
